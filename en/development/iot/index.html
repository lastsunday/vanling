IoT Firmware

Layer structure, composition, and Cargo feature criteria for the Vanling ESP32 firmware (apps/iot).

Reading order: layers first (why they are cut this way), then the feature criteria (what may come in), then how to run it and what each path means.

  • Architecture — overview and boot flow, layers, three-axis orthogonal composition, the needs model and its transport, render plugability, add-board/chip-family flows
  • Cargo Feature Criteria and Cohesion — hard/soft feature definitions, four introduction criteria, six cohesion rules
  • Firmware Installation — browser one-click install, esptool/GUI, batch flashing and debugging
  • Hardware-free Emulation and Regression Smoke — host harness + esp-emu, decision matrix, console UART constraint
  • Audio Metering Semantics — the capture semantics, screen readouts and scale, the log map's chord error, a derived release rate
  • Motion Semantic Framework — the data/semantic dual path, three-family arbitration, capability declaration, the QMI8658A register binding
  • Playback Semantics — the playback semantics, the phase of a one-shot, where the five MIDI sounds come from, the 20 ms DMA arm

Common commands and bench operations live in the Cheat Sheet.
