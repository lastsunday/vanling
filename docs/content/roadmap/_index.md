1. Splash Screen -> Network Setting Page(Ap Mode) 需在重启的时候，1.5秒内立即按住Boot键≥600 ms松开
2. Splash Screen -> Boot Page 默认自动进入
3. Page -> XX Page 使用三击Boot键，遵循预定的页面序列来进行切换
