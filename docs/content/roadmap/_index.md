优先级说明：

| 等级  | 语义                          | 示例                                   |
| ----- | ----------------------------- | -------------------------------------- |
| 🔴 P0 | 基础架构 / 影响运行的严重 bug | 核心链路缺口、认证与安全、竞态缺陷     |
| 🟠 P1 | 必要功能                      | 产品核心能力、正式发布前必须补齐的功能 |
| 🟡 P2 | 增强功能                      | 完善性提升、管理界面、可选协议支持     |
| 🔵 P3 | 可选优化                      | 体验打磨、低功耗调优等不阻塞功能的事宜 |

> 优先级由人工评估；代理仅记录，分辨不清时必须询问人类，禁止自行推断。
