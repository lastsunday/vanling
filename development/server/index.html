常见问题

服务端

vanling 服务端基于 Rust + axum 构建，实现 Xiaozhi 智能音箱协议，提供实时语音对话能力。

阅读顺序：先看核心架构（Session 与 Round 的生命周期），再看组件与管道（一轮数据怎么流），然后才是 VAD/回合判定、对话流程与协议细节；部署按需查阅。

页面说明
核心架构整体架构、Session 状态机、Round 生命周期、过滤器与构建入口
组件与模块结构核心骨架层级、双层 component、ling 特殊节点
统一管道节点契约、链的组装与释放、事件流约定
VAD 与回合判定语音起点/终点判据、两级静音闸门、回合终止路径、参数速查
对话流程握手与通讯序列图、监听模式、空输入行为
WebSocket 通信协议协议字段定义与二进制格式
模型与部署AI 模型规格、配置系统、资产安装、CUDA 部署
