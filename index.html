Vanling

[!WARNING] This project is being developed,all the things is not stable.

目的

  • 学习 Rust 编程语言、语音交互和大语言模型技术。
  • 构建一个完全自托管的聊天机器人（包含 LLM、TTS 等全部组件），类似 xiaozhi-esp32 的自托管服务端方案。

用户仪表盘

6 个统计卡片（StatCard）、趋势图（TrendsChart）、延迟分析图（LatencyChart）、延迟详情表（LatencyTable）、最近会话表（RecentSessionsTable）

特性

  • 连接：WebSocket
  • 语音交互：VAD、ASR、TTS
  • 对话：LLM
  • MCP：自托管/远程服务端 MCP、设备 MCP
  • 后台
    1. 首页（已实现：统计卡片/趋势图/延迟分析/最近会话）
    2. 管理控制台（开发中）
    3. 网页端设备模拟（开发中）
  • 部署：二进制（开发中）、Docker（开发中）
  • 兼容设备
    1. xiaozhi-esp32（开发中）
    2. vanling（Flutter 跨平台 App，开发中）
